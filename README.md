# Blind Step

Godot Engine 4.7.2.stable.steam (ed1daf0bf), Forward+, Windows. W menedżerze otwórz istniejący projekt `game/blind-step/project.godot`. F5 uruchamia Bench. Gracz startuje w PlayerSpawn. WASD steruje chodem, Shift podczas ruchu uruchamia sprint, przytrzymanie Ctrl włącza kucanie, mysz obraca widok, Esc zwalnia kursor, a lewy przycisk myszy przechwytuje go ponownie. Stanowiska obejrzysz też w widoku 3D edytora.
