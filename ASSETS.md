# Zasoby według kolejności testów

| Etap | Potrzebne zasoby |
|---|---|
| Plansza | Podłoga, ściany, niski prześwit, przesłona i wnęka z domyślnych brył z kolizją. Znacznik startu, kamera podglądu, oświetlenie referencyjne. |
| Ruch | Kapsuła gracza, kamera FPP, proceduralne przejście do kucania. Sprint i odzyskiwanie kondycji. |
| Zapałka | OmniLight3D z cieniami. Po zgaszeniu teren wraca do oświetlenia sceny. |
| Bodycam | Profil dystorsji, adaptacja cieni i ziarno. Test utrzymania orientacji przy obrocie. |
| Percepcja | Sylwetka zastępcza, nasłuch, szukanie, pogoń i cofnięcie od światła. Korytarz i boczne pomieszczenia dopiero do prób istot. |
| Próby dźwięku | Synteza kliknięcia, oddechu, kroków, wentylacji i odgłosu istoty. Test różnic między podłożami i szelestu roślin po podstawach. |
| Po akceptacji mechanik | Modele i animacje docelowe, paleta, tekstury, materiały i lokacja fabularna. |
